## 1. מראה ושמות (כל התפקידים)

- [ ] לוגו, אייקון בלשונית, צבעים (ניוד/ורוד/שזיף) וגופנים חדשים בכל המסכים.
- [ ] המילים `barbero`, `barbería`, `barba`, `corte` לא מופיעות באף מסך (בית, כניסה, יומן, Ajustes, Pagos, Análisis, הזמנה, הודעות WhatsApp).
- [ ] במקומן: `manicurista` / `manicuristas`, `spa`.
- [ ] שם העסק: **Spa Uñas Bella**, מדיין, מחירים ב-COP (למשל `$ 60.000`).

## 2. לקוחה (דף הזמנה `/r/bella`)

- [ ] רואים שירותי ציפורניים (למשל Manicure semipermanente, Acrílico, Pedicure) עם משך ומחיר.
- [ ] **כמה שירותים**: לבחור 2 שירותים. המשך הכולל והמחיר הכולל = סכום השניים, ומוצגים לפני בחירת שעה.
- [ ] **תוספות**: להוסיף `Nail art` ו-`Retiro`. המשך והמחיר עולים בהתאם.
- [ ] השעות שמוצגות מתאימות למשך הכולל (לא מוצעת שעה שאין בה מספיק זמן עד סוף היום / התור הבא).
- [ ] לבחור שעה ומניקוריסטה, להזין טלפון ושם, לשלוח. מופיע "solicitud recibida" והתור במצב `pendiente`.
- [ ] בדף התור של הלקוחה מופיעים כל השירותים והתוספות, משך ומחיר כולל.
- [ ] לקוחה חוזרת (אותו טלפון): השם מזוהה אוטומטית.
- [ ] אי אפשר לקבוע פחות משעה מראש.

## 3. מניקוריסטה

- [ ] כניסה עם הטלפון וה-PIN של מניקוריסטה.
- [ ] ביומן רואה **רק** את התורים שלה. התור מסעיף 2 מופיע כ-`pendiente` עם כל השירותים והתוספות.
- [ ] **אישור**: `Confirmar`. בלשונית WhatsApp מופיעה הודעת אישור ללקוחה. לדחות תור אחר: הודעת דחייה.
- [ ] **אלרגיות**: לקוחה עם אלרגיה: סימון בשורת התור ביומן, ובולט בפרטי התור, בכרטיס הלקוחה ובבלוק אזהרה במסך התשלום. כל צוות העסק רואה. האלרגיה **לא** מופיעה באף הודעת WhatsApp.
- [ ] **כרטיס לקוחה**: לערוך צבעים אהובים ואלרגיות, לשמור, לרענן. הנתונים נשמרו.
- [ ] בכרטיס לקוחה המניקוריסטה **לא** רואה סכומים שהלקוחה הוציאה.
- [ ] **Cobro עם טיפ**: לפתוח תור מאושר ← Cobrar. הסכום המוצע = סכום כל השירותים והתוספות. להוסיף טיפ, לבחור Nequi, לרשום. התור מסומן כשולם.
- [ ] **לחיצה כפולה**: ללחוץ מהר פעמיים על `Registrar pago` (וגם על `Confirmar`, `Guardar`). נרשם פעם אחת בלבד.
- [ ] `Mis pagos`: התשלום החדש מופיע, כולל העמלה והטיפ, עם פירוט לפי שירות.
- [ ] ביטול תור: הלקוחה מקבלת הודעת ביטול. `No vino` עובד.

- [ ] בהפעלה ראשונה כבר יש כ-17 הודעות "retoque" בלשונית WhatsApp (מנתוני הדוגמה).
- [ ] לשלם על תור Manicure semipermanente. ההודעה נשלחת ביום ה-15 בשעה 10:00 (שעון מקומי), עם לינק להזמנה.
- [ ] תור ששולם על שירות בלי מילוי (Pedicure בלבד): לא נשלחת תזכורת.
- [ ] תור שלא שולם (`no vino` / בוטל): לא נשלחת תזכורת.
- [ ] התזכורת לא נשלחת פעמיים לאותו תשלום.
- [ ] לקוחה שיש לה תור מאוחר יותר (pendiente/confirmada/שולם) לא מקבלת תזכורת.
- [ ] תשלום על תור חדש יותר מחליף את התזכורת הממתינה הקודמת (לא שתיים).
- [ ] לקוחה בלי טלפון לא מקבלת תזכורת.

## 5. בעלים

- [ ] כניסה כבעלים. ביומן רואה את כל המניקוריסטיות, סינון לפי סניף ומניקוריסטה עובד.
- [ ] **אישור שלא נענה**: תור `pendiente` שעבר המועד: מופיעה אזהרה ביומן ובלשונית WhatsApp.
- [ ] `Nueva`: לקבוע תור טלפוני עם 2 שירותים ותוספת. התור `confirmada` מיד, משך ומחיר נכונים.
- [ ] Ajustes ← שירותים: להוסיף/לערוך שירות ותוספת (משך, מחיר, מוצג/מוסתר). שירות מוסתר לא מופיע ב-`/r/bella`.
- [ ] Ajustes ← manicurista (`/app/ajustes/manicurista/<id>`): טלפון, PIN, סניף, שעות עבודה. שינוי שעות משנה את השעות הפנויות בהזמנה.
- [ ] כרטיס לקוחה: הבעלים רואה היסטוריה, סכומים, צבעים אהובים ואלרגיות.
- [ ] **עמלות**: Pagos ← מניקוריסטה: לשנות אחוז ולהוסיף חריג לשירות. הסימולציה מתעדכנת. תשלומים קודמים לא משתנים.
- [ ] תור עם כמה שירותים: כל שורת שירות מחושבת לפי הכלל שלה (% מיוחד, סכום קבוע או % כללי). הסכום ששולם מתחלק בין השורות לפי מחיר המחירון שלהן.
- [ ] **תשלום למניקוריסטה**: לרשום תשלום. היתרה "מה שחייבים" יורדת. לבטל (`anular`) את התשלום: היתרה חוזרת, והתשלום נשאר בהיסטוריה כמבוטל.
- [ ] השכרת עמדה (`arriendo`): ל-Valeria Henao מוגדר $300.000 לשבוע. לרשום תשלום שכירות, הסכום מופיע בסיכום הבעלים.
- [ ] **Análisis**: היום / שבוע / חודש, כל הרשת או סניף. הכנסות, ביקורים, ממוצע, תפוסה, טיפים. "Qué se vende" מציג שירותי ציפורניים ותוספות. "Lo que vemos" בלי מונחי מספרה.
- [ ] **גיבויים**: Ajustes ← Copias de seguridad ← להוריד גיבוי. הקובץ יורד ולא ריק.
- [ ] מניקוריסטה **לא** יכולה לפתוח Análisis, Pagos של אחרות או Ajustes (לנסות להקליד את הכתובת ישירות).

## 6. הרשמה של ספא חדש והפרדה בין עסקים

- [ ] `/registro`: לרשום ספא חדש (שם, עיר, סניף, כתובת, בעלים, טלפון 10 ספרות, PIN פעמיים).
- [ ] הטקסטים בהרשמה מדברים על `spa`, והשירותים ההתחלתיים הם שירותי ציפורניים (לא תספורת).
- [ ] הספא החדש מקבל לינק משלו `/r/<שם>` ודף הזמנה עובד.
- [ ] הבעלים של הספא החדש **לא** רואה לקוחות, תורים, מניקוריסטיות, הודעות או ניתוח של Spa Uñas Bella.
- [ ] להעתיק כתובת של כרטיס לקוחה / תור מ-Bella ולפתוח אותה כבעלים של הספא החדש: "לא נמצא", בלי נתונים.
- [ ] הרשמה עם טלפון שכבר קיים: הודעת שגיאה ברורה.
